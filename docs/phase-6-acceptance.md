# 阶段 6 验收记录

## 实现范围

- `GenerationManager` 挂载到应用根布局，聊天路由切换不重建用户级 SSE 连接。
- generation 按对话和任务分桶，聊天正文与侧边栏使用精细 selector。
- 当前页面只渲染一个聊天主区域，后台对话只更新 Store 和轻量状态。
- 侧边栏展示生成中与服务端权威未读状态，进入对话后提交已读回执。
- 草稿、生成任务和滚动位置按对话隔离，路由异步完成不会清空其他对话草稿。
- 用户 generation 并发上限可配置，默认同时运行两个任务。
- 停止按钮绑定具体 generation，并在客户端和服务端校验目标归属。

## 自动化验证

- API E2E：并发上限、终态释放额度、取消授权隔离。
- Worker E2E：终态内容持久化与未读状态更新。
- Web 单元测试：事件顺序、重复事件、对话级活动 selector。
- Playwright：A/B 并发测试默认执行 20 轮，每轮至少切换 5 次，并断言只建立一条用户事件连接。
- Playwright：停止 A 不影响 B 完成。

可通过以下命令调整竞态轮数，但默认值不得低于 20：

```bash
PHASE_6_RACE_ITERATIONS=20 pnpm --filter @chat/web test:e2e
```
